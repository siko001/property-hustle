# Property Hustle

A legal-safe Next.js property card battler with original names, card visuals, and install-ready offline support.

## Built in

- Online-style private rooms with generated codes, invite links, and QR codes.
- Local hotspot flow with a LAN secret key for offline nearby play.
- Bot tables with 2 to 6 total seats, up to 5 bots, and easy/medium/hard difficulty.
- Per-room rules for play style, team defense, chained block cards, action banking, wildcard movement, turn timers, reminders, and auto-skip.
- Playable local table prototype with hand cards, bank/property/action zones, bot moves, turn sounds, and draggable reminder toasts.
- PWA manifest and service worker for install/offline app-shell caching.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Supabase

This starter runs without Supabase. Add your keys in `.env.local` later when you want real online rooms.
